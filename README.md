# java-lotto-precourse


## 규칙 요약
- 로또 번호의 숫자 범위는 1~45까지이다.
  - 범위 벗어나면 예외처리
- 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
- 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
- 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
  - 1등: 6개 번호 일치 / 2,000,000,000원 
  - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원 
  - 3등: 5개 번호 일치 / 1,500,000원 
  - 4등: 4개 번호 일치 / 50,000원 
  - 5등: 3개 번호 일치 / 5,000원
- 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
- 로또 1장의 가격은 1,000원이다.
  - 1000원 단위로 떨어지지 않으면 예외 처리
- 당첨 번호와 보너스 번호를 입력받는다.
  - , 로 구분해서 입력을 받는다.
- 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다.
- 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
- Exception이 아닌 IllegalArgumentException, IllegalStateException 등과 같은 명확한 유형을 처리한다.
  - 예외 상황 시 에러 문구를 출력해야 한다. 단, 에러 문구는 "[ERROR]"로 시작해야 한다.

## 기능 목록
- [ ] 입력
  - [ ] 구입 금액 입력 받기
    - [ ] 비어있음/공백/숫자 아님 → IllegalArgumentException("[ERROR] ...")
    - [ ] 0 또는 음수 → 예외
    - [ ] 1,000원 단위 아님 → 예외
  - [ ] 당첨 번호 입력 받기(쉼표로 구분된 6개)
    - [ ] 공백/포맷/개수(정확히 6) 검증 실패 → 예외
    - [ ] 숫자 범위 1~45 벗어남 → 예외
    - [ ] 중복 존재 → 예외
  - [ ] 보너스 번호 입력 받기
    - [ ] 공백/숫자 아님 → 예외
    - [ ] 범위 1~45 벗어남 → 예외
    - [ ] 당첨 번호 6개와 중복 → 예외
  - [ ] 재입력 루프: 예외 발생 시 "[ERROR] ..." 출력 후 해당 단계부터 재입력

- [ ] 로또 발행
  - [ ] 구입 장수 = (구입 금액 / 1,000) 계산
  - [ ] 장수만큼 로또 생성
  - [ ] 1~45 범위에서 중복 없이 6개 추출
  - [ ] 각 로또 번호 정렬 상태로 보관/출력(선택)

- [ ] 도메인 모델
  - [ ] Lotto: 번호 6개 불변 컬렉션(생성 시 중복/개수 검증)
  - [ ] Rank(Enum): 1~5등, 미당첨
    - [ ] 필드: matchCount, matchBonus(boolean), prizeAmount
  - [ ] Result: 등수별 집계 맵, 총 상금, 수익률 계산

- [ ] 당첨 판정
  - [ ] 각 구매 로또에 대해 당첨 번호 일치 개수 계산
  - [ ] 보너스 번호 일치 여부 판단
  - [ ] Rank.of(...)로 등수 결정(else/switch 체인 금지, Enum 로직)
  - [ ] 등수별 개수 집계

- [ ] 출력
  - [ ] 발행한 로또 수량 출력
  - [ ] 각 로또 번호 출력
  - [ ] 당첨 통계 출력(3, 4, 5, 5+보너스, 6 개수와 금액)
  - [ ] 수익률 출력
    - [ ] 수익률 = (총 당첨 금액 / 구입 금액) × 100
    - [ ] 반올림 규칙 적용(일반적으로 소수점 둘째 자리)

- [ ] 예외 & 재시도 규약
  - [ ] 모든 유효성 실패는 IllegalArgumentException 사용(상태 오류는 IllegalStateException 가능)
  - [ ] 에러 출력은 반드시 "[ERROR] "로 시작
  - [ ] 예외 발생 시 해당 입력 단계로 재입력(프로그램 비정상 종료 금지)

- [ ] 설계 제약 준수(클린 코드)
  - [ ] 함수 15라인 이하, 한 가지 일만 수행
  - [ ] else/switch 금지: 가드절 + Enum 다형성/전략 패턴
  - [ ] 의미 중심 네이밍(형 힌트 금지: int/list/arr 등)
  - [ ] 입·출력(InputView/OutputView) 분리(도메인 로직과 분리)
  - [ ] 난수 생성기 인터페이스로 추상화(테스트 용이성, 선택)

- [ ] 유효성 상세 체크리스트
  - [ ] 구입 금액: 공백/문자/음수/0/1000단위 아님
  - [ ] 당첨 번호: 공백/문자 포함/개수≠6/중복/범위 위반
  - [ ] 보너스 번호: 공백/문자/범위 위반/당첨 6개와 중복
  - [ ] 로또 생성: 내부 중복 방지, 범위 보장

- [ ] 클래스 구성 예시
  - [ ] Application
  - [ ] Lotto
  - [ ] LottoController
  - [ ] Rank(Enum)
  - [ ] LottoService
  - [ ] Result(통계/수익률)
  - [ ] InputView, OutputView
  - [ ] Validator(문자열→숫자 파싱/범위/중복 검증 유틸)

- [ ] 테스트
  - [ ] LottoNumber 범위
  - [ ] Lotto 생성 시 중복/개수 검증
  - [ ] Rank.of 규칙 검증
    - [ ] 6개=1등, 5개+보너스=2등, 5개=3등, 4개=4등, 3개=5등, 그 외 미당첨
  - [ ] 수익률 계산(경계값)
  - [ ] 입력 파싱/재입력 루프(잘못 입력→다시 입력)
